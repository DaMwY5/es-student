# Занятие 3.3. Периферия ввода-вывода

Прошивка для Raspberry Pi Pico с командами через USB CDC. Логи `device-3-3-*.log`
и [осциллограмма](scope-3-3-5.png) получены в программной модели. В модели
исполняются те же обработчики команд и задачи C. Время, состояние линии,
содержимое FIFO и отсчёты АЦП вычисляются. Измерения на физической Pico ещё
предстоит провести.

| Пункт | Испытание | Результат программной модели |
| --- | --- | --- |
| 3.3.1 | `edge pp`, `edge od` | Для 4,7 мкФ фронт 4,4 мс в двухтактном режиме и 223,4 мс с открытым стоком при модельной подтяжке 50 кОм. Спад в обоих режимах 4,2 мс. |
| 3.3.2 | `loop internal\|pins`, `echo <text>` | UART0 возвращает строку через внутреннюю петлю и через модель перемычки. |
| 3.3.3 | `link`, `baud_shift`, `text`, `parity` | При одинаковой скорости проверочная строка проходит без ошибок. Первые искажения на проверенной сетке появляются при −6 % и +6 %. При −6 % есть ошибка кадра `FE`, при +6 % байты меняются без флага ошибки. Разная чётность даёт `PE`. |
| 3.3.4 | `block irq`, `block poll` | С прерыванием совпадают 64 из 64 байтов, чтение FIFO после передачи сохраняет 32 из 64 байтов и даёт `OE`. |
| 3.3.5 | `scope 115200 U`, `scope 9600 U` | Для каждой скорости получено 4096 отсчётов с шагом 2 мкс. На бит приходится около 4,34 и 52,08 отсчёта соответственно. |

На осциллограмме уровень в паузе высокий. Кадр 8N1 начинается с `0`,
передаёт `1 0 1 0 1 0 1 0` от младшего бита к старшему и заканчивается
`1`. Биты данных дают `0x55` (ASCII `U`). На 9600 бит/с каждый бит длится
примерно 104 мкс, на 115200 бит/с около 8,7 мкс.

## Сборка и моделирование

Из корня репозитория с установленными Pico SDK, Arm GCC и Ninja
(путь к SDK задан в `PICO_SDK_PATH`).

```text
cmake -S 331-uart -B build/331 -G Ninja
cmake --build build/331
```

Для воспроизведения модели нужны Python, обычный GCC и Matplotlib.

```text
python tools/test_lesson33.py --generate-model
```

## Подключение Pico для испытаний

- **3.3.1.** Соединить GP22 с GP26 через 1 кОм. Подключить конденсатор
  4,7 мкФ от GP26 к GND. У полярного конденсатора плюс подключается к GP26.
- **3.3.2.** Для внутренней петли перемычка не нужна. Для проверки через
  выводы соединить GP0 (TX0) и GP1 (RX0).
- **3.3.3–3.3.4.** Снять предыдущую перемычку и соединить GP0 с GP9,
  GP8 с GP1.
- **3.3.5.** Сохранить перекрёстные перемычки, отключить RC-цепь от GP26 и
  соединить GP0 с GP26.

После записи `331_uart.uf2` установить зависимости `pyserial` и
`matplotlib`. Из папки проекта запускать `python check-3-3-1.py` и остальные
скрипты курса по порядку, меняя соединения перед каждым пунктом.
